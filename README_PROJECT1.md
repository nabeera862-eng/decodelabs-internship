# Project 1: Data Cleaning

## Project Overview

This project focuses on cleaning an e-commerce dataset using Python and Pandas. The goal is to improve data quality by handling missing values, removing duplicates, correcting data types, and checking data consistency.

## Objectives

- Identify and handle missing values.
- Detect and remove duplicate records.
- Convert columns to appropriate data types.
- Verify TotalPrice using Quantity and UnitPrice.
- Save the cleaned dataset as a CSV file.

## Tools & Technologies

- Python
- Pandas

## Key Tasks

- Loaded the dataset using `pd.read_csv()`.
- Checked missing and duplicate values.
- Filled missing CouponCode values with `"No Coupon"`.
- Removed duplicate rows.
- Checked incorrect TotalPrice values.
- Saved the cleaned dataset as `Cleaned_Dataset1.csv`.

## Project Files

- `DECODE_LABS_PROJECT1.py` — Python code for data cleaning.
- `Dataset for Data Analytics.csv` — Original dataset.
- `Cleaned_Dataset1.csv` — Cleaned dataset.

## Conclusion

This project improved the quality and consistency of the e-commerce dataset and prepared it for further data analysis.
